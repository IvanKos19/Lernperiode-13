# Lernperiode-13

## Ziel und Vorgehen der Sitzung
In der ersten Sitzung der Lernperiode 13 arbeite ich mich selbstständig in eine neue, frei gewählte Technologie ein. Ziel ist es, einen Überblick über mögliche Technologien zu gewinnen, eine begründete Auswahl zu treffen und einen ersten Einstieg durch einfache Beispiele und Tutorials zu machen. Gleichzeitig dokumentiere ich mein Vorgehen nachvollziehbar, sodass es später als Grundlage für einen Blog-Beitrag dienen kann.
Zu Beginn habe ich verschiedene Technologien recherchiert, die für mich neu sind, darunter TypeScript, Svelte und Rust. Dabei habe ich mir angeschaut, wofür diese Technologien eingesetzt werden und welche Vorteile sie gegenüber mir bekannten Lösungen haben. Anschließend habe ich mich für TypeScript entschieden, da es stark in der Webentwicklung verbreitet ist und mir hilft, strukturierter und typsicherer zu programmieren.

### Vergleich möglicher Technologien
1. TypeScript

TypeScript ist eine von Microsoft entwickelte Erweiterung von JavaScript, die statische Typisierung ermöglicht. Dadurch lassen sich Fehler früher erkennen, was besonders bei grösseren Projekten von Vorteil ist. Viele moderne Frameworks wie React, Angular oder Node.js unterstützen TypeScript nativ, weshalb es eine sinnvolle Grundlage für zukünftige Projekte darstellt.
TypeScript besitzt eine sehr gute Dokumentation und zahlreiche Tutorials, was den Einstieg erleichtert. Obwohl ich bereits viel mit JavaScript gearbeitet habe, habe ich TypeScript bisher noch nicht aktiv in eigenen Projekten eingesetzt.
(https://www.typescriptlang.org/docs/)

2. Svelte

Svelte ist ein modernes JavaScript-Framework zur Entwicklung von Webapplikationen. Im Vergleich zu React oder Vue wird viel Logik bereits beim Kompilieren verarbeitet, was zu sehr performanten Anwendungen führt. Svelte gilt als einsteigerfreundlich und benötigt weniger Boilerplate-Code als andere Frameworks.
Ich habe Svelte bisher noch nie verwendet, finde den Ansatz jedoch spannend. Trotzdem ist die Verbreitung im Vergleich zu React oder TypeScript geringer, was langfristig ein Nachteil sein kann.
(https://svelte.dev/docs)

3. Rust

Rust ist eine moderne Programmiersprache mit Fokus auf Performance und Speichersicherheit. Sie wird häufig für systemnahe Anwendungen oder performante Backend-Komponenten eingesetzt. Rust gilt jedoch als vergleichsweise schwierig zu erlernen und hat eine steile Lernkurve.
Für diese Lernperiode wäre Rust vermutlich zu komplex, da der Fokus auf einem einfachen Einstieg in eine neue Technologie liegen soll.
(https://www.rust-lang.org/learn)

Entscheidung

Ich entscheide mich für TypeScript, da es mir aus meiner Sicht die meisten Vorteile für zukünftige Projekte bietet. Da TypeScript stark auf JavaScript aufbaut, kann ich vorhandenes Wissen nutzen und gleichzeitig neue Konzepte wie Typisierung und Interfaces lernen. Dieses Wissen lässt sich später direkt in Frameworks wie React oder Node.js anwenden.

Der Grund, weshalb ich mich gegen Svelte entschieden habe, ist die geringere Verbreitung im Vergleich zu TypeScript. Rust habe ich nicht gewählt, da der Einstieg für diese Lernperiode zu aufwendig wäre und nicht zum Ziel eines einfachen, überschaubaren Projekts passt.
